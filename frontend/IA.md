1. Information Architecture (IA)

서비스의 정보 구조는 좌측 사이드바(LNB)를 기준으로 크게 General(메인), Study(학습), Exam(시험), Chat(AI 질의응답) 4가지 뎁스로 나뉩니다.

    1. General (메인페이지)

      

        1.1. 대시보드

            학습 연속일(Study Streak) 표시  

            현재 진행 중인 스터디 요약 및 진행률(%)  

            '이어하기' 버튼 (예: 빈칸 문제 풀러가기)  

    2. Study (과목별 학습)

      

        2.1. 과목 선택 (성공적인 직업생활 / 공업 일반)  

        2.2. 단원 리스트 및 진행률 조회 (1단원 ~ n단원)  

        2.3. 단원별 학습 모드 진입  

            2.3.1. 기초 개념 학습  

            2.3.2. 빈칸 문제 풀기 (문장 내 핵심 키워드 빈칸 채우기)  

            2.3.3. 양방향 개념 문제 풀이 (키워드 ↔ 속성 매칭 퀴즈)  

            2.3.4. 실전 문제 풀이  

            2.3.5. 오답 재풀이  

    3. Exam (맞춤형 시험 및 문제 풀이)

      

        3.1. 과목별 시험 홈 (성공적인 직업생활 문제 / 공업 일반 문제)  

        3.2. 문제 생성 (모달/페이지)  

            단원 범위 설정 (예: 1단원 ~ 2단원)  

            문제 개수 설정  

            난이도 설정 (초급, 중급, 고급, 고난이도, 극상 등)  

            전용 프롬프트 (커스텀 요구사항 입력)  

        3.3. 시험 결과 및 상세 페이지  

            점수 및 대표 태그 확인 (예: 직업탐구, 퇴직금 등)  

            오답노트 및 미리보기  

            틀린문제 다시풀기 / 전체문제 다시풀기  

            PDF로 추출 (Export)  

    4. Chat (AI 튜터 질의응답)

      

        4.1. AI 채팅방 홈 (성공적인 AI)  

        4.2. 검색 범위(Scope) 설정 (전 단원 등 특정 범위 한정 가능)  

        4.3. 과거 채팅 내역 (LNB 하단 리스트)
