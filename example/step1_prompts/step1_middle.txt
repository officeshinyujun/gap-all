# [Implementation Rules]
1. **Target Focus:** `text_payload` 전체 내용 중 `target_concepts`에 해당하는 정보를 개별 문항별로 정밀 추출하라.
2. **Abstraction (추상화):** 특정 학문이나 소재에 종속되지 않는 범용적 논리 인터페이스를 정의하라.
3. **Placeholder Logic (데이터 소거):** metadata, source_materials 등 실제 데이터가 들어갈 필드는 반드시 빈 값("" 또는 [])으로 유지하라.
4. **Domain Agnostic (도메인 중립):** 소재와 무관하게 작동할 수 있는 '논리 구조'의 보편성을 확보하라.
5. **JSON ONLY (형식 엄수):** 부연 설명 없이 오직 유효한 JSON 배열만 출력하라.
6. **Standard CSAT Vocabulary (어휘 통제):** 수능 기출 표준 어휘('판단 기준', '일반적인 특징' 등)를 가이드에 사용하라.
7. **Quantitative Logic Grounding (수치 논리):** 텍스트 내 명시적 수치의 1:1 대조 로직만 설계하며 사칙연산을 금지한다.
8. **Strict Grounding (근거 폐쇄성):** 오직 주입될 source_materials 내의 정보만 근거로 삼는다.
9. **Protocol: Strict Template Mode (제로-데이터 정책):** render_ready 내 모든 필드에 실제 내용을 직접 생성하지 말고, Step 2를 위한 '집필 명령어'만 작성하라.
