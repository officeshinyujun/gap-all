# [난이도 하 설계 원칙]
- 단순 개념 확인: 교과서에 명시된 정의·특징·분류를 직접 판별하는 수준
- 보기 진위 배정: 4개 보기 중 2개 참 / 2개 거짓을 기본으로 한다
- 판단 축: 하나의 명확한 기준(정의 일치, 분류 소속, 특징 해당 여부)으로 판별 가능
- 단서 배치: 각 보기의 참·거짓을 판단할 수 있는 근거가 text_payload 내 1~2문장에서 바로 확인 가능
- 오답 설계: 같은 단원 내 유사 개념의 단순 혼동(긍정/부정 변환, 인접 분류 오적용)
- 보기 개수 선택: 판단해야 할 독립 진술이 3개면 view_count: 3 (exhaustive_subset), 4개면 view_count: 4 (combination_judgment)
- 성직 과목은 view_count: 3을 전체의 40% 이상 사용하는 것을 권장 (실제 수능 비율 반영)

# [문항 유형 선택 규칙 — 기본형 강제 금지]
아래 규칙에 따라 `item_structure.item_family`를 먼저 결정한 뒤 나머지 필드를 설계하라. **조합형(combination_judgment)은 핵심 유형이지만 기본값이 아니다.** 발문/자료 구조가 조합형을 요구할 때만 사용하라.

1. `combination_judgment`
- 발문에 `<보기>`가 포함되거나, ㄱ·ㄴ·ㄷ·ㄹ 여러 진술의 참/거짓을 조합으로 판단해야 할 때만 선택
- `choice_encoding_type`은 `truth_combination`
- `judgment_map`, `choice_encoding_plan` 필수

2. `single_selection`
- ①~⑤가 서로 독립된 후보(프로그램명, 시스템명, 면접 유형, 직업 가치 유형, 제도명, 개념 유형 등)일 때 선택
- 발문 예: `가장 적절한 것은?`, `옳은 것은?`, `옳지 않은 것은?`
- `choice_encoding_type`은 `independent_options`
- `judgment_map`, `choice_encoding_plan`은 비워 두거나 생략 가능

3. `blank_workflow`
- `(가)`, `(나)` 또는 단계/절차/순서도 빈칸 대응이 핵심일 때 선택
- 흐름도, 단계도, 진로 결정 절차, NCS 탐색 단계 등에서 우선 고려
- `choice_encoding_type`은 `independent_options`

4. `direct_statement`
- 기사, 보고서, 기술 저널, 채용 공고, NCS 화면, 설문표 등을 읽고 단일 진술을 바로 판별하는 문제일 때 선택
- 자료 직접 해석형으로, <보기> 없이도 충분히 성립하는 구조에 사용
- `choice_encoding_type`은 `independent_options`

5. `exhaustive_subset`
- 보기 3개(ㄱ, ㄴ, ㄷ)의 참/거짓을 판정한 뒤 "적절한 것만을 <보기>에서 있는 대로 고른 것은?" 발문 사용
- view_count는 3
- choice_encoding_type은 `subset_exhaustive`
- judgment_map에 ga, na, da만 사용 (ra 생략)
- choice_encoding_plan에 참인 보기 부분집합으로 ①~⑤ 구성
- 선지 예시 (참: ㄴ,ㄷ): ① ㄱ  ② ㄷ  ③ ㄱ,ㄴ  ④ ㄴ,ㄷ  ⑤ ㄱ,ㄴ,ㄷ

6. `label_matching`
- 자료(표, 연표, 분류도)에 빈칸 라벨(가)~(다)가 있고, 보기(ㄱ~ㄹ) 중 적절한 것을 각 라벨에 매칭하는 문제
- 발문 예: "(가)~(다)로 가장 적절한 것을 <보기>에서 고른 것은?"
- `choice_encoding_type`은 `permutation_matching`
- `judgment_map` 대신 `label_answer_map` 사용: { "가": "ㄴ", "나": "ㄹ", "다": "ㄷ" }
- 선지 형식: "① (가)-ㄱ, (나)-ㄴ, (다)-ㄷ"

7. `pair_selection`
- 발문이 2개의 판단 축을 동시에 묻는 문제 (예: 윤리유형 × 기업가정신)
- 발문 예: "다음 기사에 나타난 직업 윤리와 기업가 정신으로 가장 적절한 것은?"
- `choice_encoding_type`은 `independent_options`
- 선지는 (축1 값, 축2 값) 쌍으로 구성: "① 환경 윤리, 진취성"
- Blueprint에 `pair_axes` 필드 추가:
  { "axis_1": "직업 윤리 유형", "axis_2": "기업가 정신 유형" }

# [과목별 우선 선택 힌트]
- 성직: 채용 공고, 면접 장면, NCS 화면, 취업 프로그램 안내, 기사/칼럼은 `single_selection` 또는 `direct_statement` 우선
- 성직: 가치관/윤리/제도 비교에서 여러 진술을 동시에 판정해야 하면 `combination_judgment`
- 공일: 시스템명(MES/SCM/CRM/JIT/POP), 공정/기법/분류 중 하나를 고르는 문제는 `single_selection` 우선
- 공일: 보고서/표/기사에서 내용을 종합해 단일 판단을 하는 문제는 `direct_statement` 우선
- 공일·성직 공통: `(가)` 빈칸, 단계 절차, 순서도는 `blank_workflow` 우선
- 성직·공일 공통: 판정해야 할 독립 진술이 정확히 3개이고 "있는 대로" 고르게 할 때 `exhaustive_subset` 사용
- 성직·공일 공통: 연대표/분류표에 (가)~(다) 빈칸이 있고 보기를 매칭할 때 `label_matching` 사용
- 성직: 기사/사례에서 2개 개념을 동시에 식별할 때 (예: 윤리+정신, 가치+유형) `pair_selection` 사용
- 이론 적용 문항(해비거스트, 하렌, 홀랜드, 슈메너, 호프만, 클라크 등): theory_constraint 필수

# [수치 계산 문항 가이드]
이 과목의 실제 수능은 노동법/사회보험법 기반 계산 문항을 포함한다. 아래 유형에 해당하는 개념은 계산 문항으로 설계하는 것을 권장한다:
- 근로시간/야간근로/연장근로 관련 개념 → 수치 계산 포함
- 임금/수당/최저임금/주휴수당 관련 개념 → 수치 계산 포함
- 퇴직금/사회보험료 관련 개념 → 수치 계산 포함
- 출산전후휴가·육아휴직 급여 관련 개념 → 수치 계산 포함
- 실업급여(구직급여) 관련 개념 → 수치 계산 포함
계산 문항의 경우 stimulus_data에 구체적 수치를 포함하고, judgment_map의 claim에 계산 로직을 반영하라.
계산 문항의 point_value는 3으로 설정하라.


# [이론 참조(theory_constraint) 가이드]
실제 수능은 자주 특정 학자의 이론을 이름으로 직접 참조한다. 아래는 자주 인용되는 학자들이다:
- 해비거스트(Havighurst, R. J.): 생애 발달 단계별 발달 과업
- 하렌(Harren, V. A.): 진로 의사 결정 유형(합리적/직관적/의존적)
- 슈퍼(Super, D. E.): 진로 발달 이론
- 긴즈버그(Ginzberg, E.): 진로 선택 과정
- 홀랜드(Holland, J. L.): 직업 흥미 유형(RIASEC)
- 슈메너(Schmenner, R. W.): 서비스 프로세스 매트릭스
- 클라크(Clark): 제조업 분류
이론 참조가 필요한 문항은 theory_constraint 필드에 이론 정보를 명시하고, 발문에 "(단, [학자명]의 [이론명]에 근거한다.)" 형태로 포함하라.


# [단원별 생성 규칙 — 성직]
아래는 EBS 수능특강 2027 분석 기반 단원별 특화 규칙이다. Blueprint 생성 시 text_payload만으로 단원을 식별하여 해당 단원의 규칙을 적용하라.

## 1단원 (일과 직업 및 직업 생활)
- 말투: 생활 사례체, 상담체. 가장 생활밀착형. 봉사·급여·생계·보람 등 가치 단서를 촘촘히 배치.
- 자료 형식: 사례문, 상담 대화, SNS, 진로 계획 발표문, AI 대화
- 오답 설계: 내재적/외재적 가치 혼동, 홀랜드 유형 혼동 (RIASEC)
- 특이사항: 홀랜드 성격 유형 코드 직접 사용 가능. 직업의 4요건(계속성/경제성/사회성/윤리성) 활용.

## 2단원 (생애 발달과 직업적 성공 1)
- 말투: 설명문 + 상담체. 학자 이론을 이름으로 직접 인용 필수.
- 자료 형식: 발달 단계 사례, 대화, 보고서, 기사, 일기, 진단표, 강연문
- 학자 직접 인용 필수: 해비거스트(Havighurst), 레빈슨(Levinson), 슈퍼(Super), 마샤(Marcia), 에릭슨(Erikson)
- theory_constraint 필수: 발문 말미에 "(단, [학자명]의 [이론명]에 근거한다.)" 형태로 포함
- 오답 설계: 학자별 이론 내용 혼동 (각 학자의 발달 단계/과업을 서로 바꿔치기)

## 3단원 (생애 발달과 직업적 성공 2)
- 말투: 학생 발표체, 사례문체
- 자료 형식: 보고서, 인터뷰, SNS, Johari Window 진단표, 능력 검사 결과표, 수업 장면
- 특이사항: Johari Window(자아 인식 프레임워크) 직접 사용 가능
- 타단원 혼합 허용: 1~2단원(직업가치/생애발달) 개념과 결합한 복합형 문제

## 4단원 (기업의 종류와 형태별 특징)
- 말투: 설명문체. 법적·경제적 개념을 명확히 구분.
- 자료 형식: 대화, 표, 기업 사례, 회의록, 컨설팅 대화, 사업 보고서
- 오답 설계: 법적 형태(합명/합자/유한/주식회사)의 목적·소유·책임 구조 혼동
- 특이사항: Carroll의 CSR 피라미드(경제적/법적/윤리적/자선적 책임) 인용 가능. 공기업/사기업/공사합동 구분.

## 5단원 (기업의 경영 활동)
- 말투: 실무 설명체
- 자료 형식: 표, 인터뷰, 기업 자료, 퀴즈 대회, 드라마 등장인물 소개, 재무제표, 채용 공고
- 오답 설계: 경영 활동 기능별 혼동 (생산/마케팅/인사/재무/회계 각각의 목적과 활동을 서로 바꿔치기)
- 특이사항: STP(세분화-표적-포지셔닝), 4P 마케팅믹스, 재무제표(대차대조표/현금흐름표) 프레임워크 사용 가능

## 6단원 (제조업과 제품 생산 활동)
- 말투: 설명문 + 사례문. 공일보다 생활 언어 강함.
- 자료 형식: 사례, 대화, 보고서, 표, 입지 선정 문서, 기업 발표자료
- 오답 설계: Hoffmann 비율(생산재/소비재), Clark 산업분류(1/2/3차), 생산방식(개별/로트/연속/프로젝트) 혼동
- 계산 포함: Hoffmann 비율 계산 가능 (생산재 출하액 / 소비재 출하액)
- 특이사항: JIT 시스템, KSIC(한국표준산업분류) 코드 참조 가능

## 7단원 (서비스업과 서비스 생산)

- 오답 설계: 서비스 4대 특성(무형성/동시성/이질성/소멸성) 혼동
- 특이사항: Schmenner 서비스 프로세스 매트릭스(노동집약도 × 상호작용·맞춤화) 인용 가능

## 8단원 (직업 기초 능력의 종류와 향상)

- 오답 설계: 직업기초능력 10개 영역 혼동 (의사소통/수리/문제해결/정보/기술/자원관리/조직이해/대인관계/자기개발/직업윤리)
- 특이사항: NCS 능력단위 참조 가능. NCS 자기소개서 구성요소(STAR 기법) 활용 가능.

## 9단원 (전공별 직무 수행 능력 탐색 1)

## 11단원 (경력 개발과 평생 학습의 의미)

- 특이사항: 블로그 형식, 법률 조문 직접 인용 가능. 디지털 배지 시스템 개념 포함.

## 12단원 (취업과 창업 및 기업가 정신 1)

## 13단원 (취업과 창업 및 기업가 정신 2)

- 특이사항: STAR 기법(상황-과제-행동-결과), 역량평가표, AI 평가 트렌드 반영 가능

## 14단원 (취업과 창업 및 기업가 정신 3)

- 타단원 혼합 허용: 4단원(기업형태) 개념과 결합 가능
- 특이사항: 레이다 차트, 창업 적성 검사 형식 사용 가능. 프랜차이즈 창업 절차 상세.

## 15단원 (근로관계와 법 1)

- 특이사항: 하인리히 4원칙·5단계 예방 과정 직접 인용. 안전보건표지(금지/경고/지시/안내) 종류 사용.

## 19단원 (협력적인 노사 관계)

- 자료 형식: 사례, 대화, SNS, 보고서, 뉴스기사(다수), SNS 대화
- 오답 설계: 노동조합 종류(직업별/산업별/기업별/일반) 혼동, 사용자단체(경총/한국무역협회) 명칭 혼동

- 특이사항: 나노기술·스마트워크·그린성장 등 미래 기술 구체적 사례 포함. 정보윤리(해킹/개인정보), 환경윤리(지속가능) 실제 사례 활용. 유망직업군(녹색/IT/첨단기술/국제전문가) 제시.

## 1단원 (일과 직업 및 직업 생활)
- 말투: 기술 교과서체, 산업 현장 중심. 직업의 의미를 산업 분류와 연결하여 서술.
- 자료 형식: 표(산업분류), 직무 분석표, 기업 현장 자료, 작업자 인터뷰
- 오답 설계: 직업의 4요건(계속성·경제성·사회성·윤리성) 혼동, 산업분류(1/2/3차) 구분 오류
- 특이사항: Clark 산업분류 체계(1차→2차→3차) 직접 사용. 산업별 고용 비중 데이터 포함 가능.

## 2단원 (경공업의 개요)
- 말투: 산업 분류 설명체. 경공업의 특징과 세부 업종을 체계적으로 서술.
- 자료 형식: 분류표, 생산 공정도, 업종별 비교표, 원자재 가공 흐름도
- 오답 설계: 경공업 vs 중화학공업 범주 혼동, 경공업 세부 업종(섬유·의류·식품·가구·제지 등)의 원자재·제품 구분 오류
- 특이사항: 경공업의 원료 의존형 특성(농수산물 가공), 노동집약적 생산 방식 강조

## 3단원 (중화학 공업의 개요)
- 말투: 기술 분석체. 중화학공업의 규모와 기술 복잡성을 강조.
- 자료 형식: 분류표, 생산 설비 도식, 업종 간 연관 관계도, 원자재 흐름도
- 오답 설계: 중화학공업 세부 업종(석유화학·철강·자동차·조선·전자 등) 구분 오류, 장치산업 vs 조립산업 혼동
- 특이사항: 중화학공업의 자본집약적·기술집약적 특성. 전후방 연관 효과(iron&steel→automotive) 개념 사용 가능.

## 4단원 (첨단 공업과 미래 사회)
- 말투: 미래 전망체. 신기술과 산업 변화 중심.
- 자료 형식: 기술 비교표, 산업 발전 단계도, 기술 도입 효과 분석표, 신규 직업 소개
- 오답 설계: 첨단기술(IT/BT/NT/ET) 분야별 특성 혼동, 산업 구조 변화 방향 오해석(탈공업화 vs 재공업화)
- 특이사항: 4차 산업혁명 기술(IoT·AI·빅데이터·클라우드)의 산업 적용 사례 포함 가능

## 5단원 (제품과 제조 과정)
- 말투: 공정 설명체. 제조 과정의 각 단계를 기술적으로 서술.
- 자료 형식: 제조 공정도, BOM(자재명세서), 생산 계획표, 제품 설계 도면, 가공 흐름도
- 오답 설계: 제조 공정 단계(설계→조달→가공→조립→검사→출하) 순서 혼동, 개별생산/소량생산/대량생산 특성 혼동
- 계산 포함: 생산량 계산(가동률·사이클타임), 재고 회전율(연간매출÷평균재고), BOM 분석
- 특이사항: 제품의 3대 구성 요소(재질·가공·조립), 생산 방식(개별/로트/연속) 직접 사용

## 6단원 (제품의 표준화)
- 말투: 규격·기준 설명체
