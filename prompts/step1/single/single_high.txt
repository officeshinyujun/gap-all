# [난이도 '상' 설계 원칙]
1. **복합 추론:** 2개 이상의 조건을 동시에 검토하고, 여러 문장에 분산된 단서를 종합해야 판단 가능한 수준.
2. **보기 진위 배정:** 4개 보기 중 2개 참 / 2개 거짓. 각 보기의 참·거짓 판단에 다중 조건 검토가 필요하다.
3. **단서 배치:** text_payload 내 서로 떨어진 3개 이상의 문장 정보를 조합해야 결론에 도달할 수 있도록 설계한다.
4. **오답 설계:** 부분적 참(partial truth), 경계값 미세 오판, 조건 누락을 활용한다.

# [문항 유형 선택 규칙 — 기본형 강제 금지]
아래 규칙에 따라 `item_structure.item_family`를 먼저 결정한 뒤 나머지 필드를 설계하라. **조합형(combination_judgment)은 핵심 유형이지만 기본값이 아니다.** 발문/자료 구조가 조합형을 요구할 때만 사용하라.

1. `combination_judgment`
- 발문에 `<보기>`가 포함되거나, ㄱ·ㄴ·ㄷ·ㄹ 여러 진술의 참/거짓을 조합으로 판단해야 할 때만 선택
- `choice_encoding_type`은 `truth_combination`
- `judgment_map`, `choice_encoding_plan` 필수

2. `single_selection`
- ①~⑤가 서로 독립된 후보(프로그램명, 시스템명, 면접 유형, 직업 가치 유형, 제도명, 개념 유형 등)일 때 선택
- 발문 예: `가장 적절한 것은?`, `옳은 것은?`, `옳지 않은 것은?`
- `choice_encoding_type`은 `independent_options`
- `judgment_map`, `choice_encoding_plan`은 비워 두거나 생략 가능

3. `blank_workflow`
- `(가)`, `(나)` 또는 단계/절차/순서도 빈칸 대응이 핵심일 때 선택
- 흐름도, 단계도, 진로 결정 절차, NCS 탐색 단계 등에서 우선 고려
- `choice_encoding_type`은 `independent_options`

4. `direct_statement`
- 기사, 보고서, 기술 저널, 채용 공고, NCS 화면, 설문표 등을 읽고 단일 진술을 바로 판별하는 문제일 때 선택
- 자료 직접 해석형으로, <보기> 없이도 충분히 성립하는 구조에 사용
- `choice_encoding_type`은 `independent_options`

# [과목별 우선 선택 힌트]
- 성직: 채용 공고, 면접 장면, NCS 화면, 취업 프로그램 안내, 기사/칼럼은 `single_selection` 또는 `direct_statement` 우선
- 성직: 가치관/윤리/제도 비교에서 여러 진술을 동시에 판정해야 하면 `combination_judgment`
- 공일: 시스템명(MES/SCM/CRM/JIT/POP), 공정/기법/분류 중 하나를 고르는 문제는 `single_selection` 우선
- 공일: 보고서/표/기사에서 내용을 종합해 단일 판단을 하는 문제는 `direct_statement` 우선
- 공일·성직 공통: `(가)` 빈칸, 단계 절차, 순서도는 `blank_workflow` 우선
