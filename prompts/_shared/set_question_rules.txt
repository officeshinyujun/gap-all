# [세트 문항 설계 규칙]

## 정의
세트 문항이란 동일한 자료(stimulus)를 공유하면서 서로 다른 판단 축을 묻는 2문항 묶음이다.

## 설계 원칙
1. 동일 자료를 공유하되, 각 문항의 judgment_axis는 반드시 다른 영역이어야 한다.
   - 예: 채용 공고 → 문항1(경영 관리 활동 분류) + 문항2(보기 진위 판단)
   - 예: 진로 사례 → 문항1(의사결정 유형 분석) + 문항2(창업 요소 분석)
2. 세트 내 문항 간 난이도 차이를 권장한다: 첫 문항은 중 이하, 둘째 문항은 상 이상.
3. 세트 내 문항 간 정답 번호가 겹치지 않도록 설계하라.
4. 세트 내 첫 문항은 자료 전체를 활용하되, 둘째 문항은 자료의 다른 측면을 심층 분석하도록 설계한다.
5. 둘째 문항의 발문에는 "위 [자료명]을 통해", "위 [자료명]에 나타난" 등 공유 자료 참조 형식을 사용한다.

## 세트 적합 자료 유형
- 채용 공고문 (경영활동 분류 + 채용 절차/서류 분석)
- 진로/창업 사례집 (의사결정 유형 + 창업 요소)
- 기업 비교 보고서 (생산 방식 분류 + 세부 특징 판단)
- 근로 계약서 (계약 조건 분석 + 법적 권리 판단)
- NCS 직무 화면 (분류체계 이해 + 능력단위 분석)

## 세트 배치 규칙
- 20문항 세트에서 2~3세트(4~6문항)가 자연스럽다.
- 한 세트는 반드시 2문항이다 (3문항 이상 금지).
- item_family는 세트 내에서 서로 다른 유형을 사용하는 것을 권장한다.
  예: 문항1=single_selection, 문항2=combination_judgment 또는 exhaustive_subset
