1. **Placeholder Logic (데이터 소거):** metadata, source_materials 등 실제 데이터가 들어갈 필드는 반드시 빈 값("" 또는 [])으로 유지하라.
2. **JSON ONLY (형식 엄수):** 부연 설명 없이 오직 유효한 JSON 코드 블록만 출력하라.
3. **Standard CSAT Vocabulary (어휘 통제):** 수능 기출 및 EBS 수능특강 표준 어휘('판단 기준', '일반적인 특징' 등)를 가이드에 사용하라. 교과 개념어를 직접 사용해도 된다.
4. **Quantitative Logic Grounding (수치 논리):** 텍스트 내 명시적 수치의 1:1 대조 로직만 설계하라. 사칙연산을 금지한다.
5. **Strict Grounding (근거 폐쇄성):** 오직 주입될 source_materials 내의 정보만 근거로 삼는다. text_payload 외부의 지식을 근거로 사용하지 마라.
6. **Protocol: Strict Template Mode (제로-데이터 정책):** render_ready 내 모든 필드에 실제 내용을 절대 직접 생성하지 마라. 대신 Step 2를 위한 '집필 명령어'만 작성하라.
7. **Logical Entanglement (논리적 얽힘):** '상' 이상의 문항에서는 서로 떨어진 두 문장 이상의 정보를 조합해야만 결론에 도달할 수 있도록 설계하라. (단일 문장 복사-붙여넣기식 설계 금지)
8. **Attractive Distractor — Curriculum-Adjacent Confusion (교육과정 인접 혼동):** 오답 선지는 단순히 '틀린 말'이 아니라, 같은 단원 또는 인접 단원의 유사 개념을 잘못 적용했을 때 도달하게 되는 '교육과정 인접 혼동의 산물'이어야 한다. 공일은 산업 분류/공정/관리 기법 혼동, 성직은 가치관/면접유형/법/NCS 개념 혼동을 우선 활용하라.
9. **Semantic Paraphrasing (의미적 치환 — 자연스러울 때 선호):** 정답 선지 구성 시 지문의 핵심 어휘를 그대로 반복하기보다 상위 개념, 하위 사례, 또는 의미적 동의어로 치환하는 것을 선호한다. 단, 교과 표준 용어이거나 치환이 부자연스러운 경우에는 원어 그대로 사용해도 무방하다.
10. **Chain of Reasoning (추론 사슬):** '극상(Killer)' 문항은 [원리 파악] -> [조건 매칭] -> [사례 대입]의 최소 3단계 사고 과정을 거치도록 설계 가이드를 작성하라.
11. **Stem-Option Coherence (발문-선지 정합성):** 발문(question_stem)이 묻는 대상과 선지(options_list)가 답하는 대상은 반드시 동일한 범주여야 한다. 발문이 '원인'을 물으면 선지도 '원인'을 나열하고, '특징'을 물으면 선지도 '특징'을 서술하라. 발문의 주어/목적어와 선지의 서술 대상이 불일치하면 출제 오류로 간주한다.
12. **Option Category Unity (선지 범주 통일):** 5개 선지는 반드시 동일한 문법적 형태(모두 명사구, 모두 서술문, 모두 판단문 등)로 통일하라. 일부는 단어이고 일부는 문장인 혼합 구성은 절대 금지한다.
13. **Correct Answer Necessity (정답 필연성):** 정답 선지는 지문 근거에 의해 '유일하게' 옳은(또는 유일하게 틀린) 것이어야 한다. 정답과 오답 사이에 모호한 경계가 존재하면 출제 오류로 간주한다.
14. **Concept Usage Principle (개념어 사용 원칙):** 교과 개념어를 발문이나 보기에 사용할 수 있다. 단, 개념어의 단순 노출만으로 정답이 결정되어서는 안 된다. 개념어가 등장하더라도 수험생이 자료를 해석하고 판단을 적용해야 정답에 도달하도록 설계하라.
    - [허용] 발문에 개념어가 등장하되, 자료 해석·적용·비교가 필요한 경우
    - [허용] "다음 자료에 대한 설명으로 옳은 것은?", "위 사례에 적용된 원리로 적절한 것은?"
    - [금지] 개념어만 읽으면 자료 없이도 답을 고를 수 있는 단순 정의 확인형
    - 자료(stimulus_data)가 문항의 핵심 판단 근거로 기능해야 한다.
15. **Subject-Specific Tone Adherence (과목별 톤 준수):** 생성되는 문항의 말투와 자료 형식은 해당 과목의 코퍼스 톤을 따라야 한다.
    - 공일: 기술 교과서체, 보고서체, 행정문체. 건조하고 기술적인 어조.
    - 성직: 상담체, 안내문체, 생활문체. 학생 친화적이고 상황 중심적인 어조.
    - 과목 톤에서 벗어난 문항은 스타일 오류로 간주한다.
16. **조합형 Item Structure Rule (보기 진위 배정 명시):** 조합형 문항(item_family: combination_judgment)을 설계할 때는 반드시 다음을 명시하라:
    - 각 보기(ㄱ~ㄹ)의 진술 내용(claim)
    - 각 보기의 참/거짓 판정(truth) 및 그 근거(evidence_anchor)
    - ①~⑤ 선택지가 어떤 보기 조합을 인코딩하는지(choice_encoding_plan)
    - 정답 선택지는 참인 보기만을 정확히 포함해야 하며, 오답 선택지는 최소 하나의 거짓 보기를 포함하거나 참인 보기를 누락해야 한다.
