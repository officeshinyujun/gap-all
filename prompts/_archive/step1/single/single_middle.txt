# [난이도 중 설계 원칙]
- 개념 적용: 교과 개념을 새로운 사례·자료에 적용하여 판단하는 수준
- 경계값 판단: 유사 개념 간 경계에서 올바른 분류·적용을 요구
- 보기 진위 배정: 4개 보기 중 2개 참 / 2개 거짓을 기본으로 하되, 참/거짓 판정에 1단계 추론(조건 매칭) 필요
- 판단 축: IF-THEN 형태의 기초 인과 관계 또는 조건 매칭
- 단서 배치: 각 보기의 참·거짓을 판단하려면 text_payload 내 2~3문장의 정보를 연결해야 함
- 보기 개수 선택: 판단해야 할 독립 진술이 3개면 view_count: 3 (exhaustive_subset), 4개면 view_count: 4 (combination_judgment)
- 성직 과목은 view_count: 3을 전체의 40% 이상 사용하는 것을 권장 (실제 수능 비율 반영)

# [문항 유형 선택 규칙 — 기본형 강제 금지]
아래 규칙에 따라 `item_structure.item_family`를 먼저 결정한 뒤 나머지 필드를 설계하라. **조합형(combination_judgment)은 핵심 유형이지만 기본값이 아니다.** 발문/자료 구조가 조합형을 요구할 때만 사용하라.

1. `combination_judgment`
- 발문에 `<보기>`가 포함되거나, ㄱ·ㄴ·ㄷ·ㄹ 여러 진술의 참/거짓을 조합으로 판단해야 할 때만 선택
- `choice_encoding_type`은 `truth_combination`
- `judgment_map`, `choice_encoding_plan` 필수

2. `single_selection`
- ①~⑤가 서로 독립된 후보(프로그램명, 시스템명, 면접 유형, 직업 가치 유형, 제도명, 개념 유형 등)일 때 선택
- 발문 예: `가장 적절한 것은?`, `옳은 것은?`, `옳지 않은 것은?`
- `choice_encoding_type`은 `independent_options`
- `judgment_map`, `choice_encoding_plan`은 비워 두거나 생략 가능

3. `blank_workflow`
- `(가)`, `(나)` 또는 단계/절차/순서도 빈칸 대응이 핵심일 때 선택
- 흐름도, 단계도, 진로 결정 절차, NCS 탐색 단계 등에서 우선 고려
- `choice_encoding_type`은 `independent_options`

4. `direct_statement`
- 기사, 보고서, 기술 저널, 채용 공고, NCS 화면, 설문표 등을 읽고 단일 진술을 바로 판별하는 문제일 때 선택
- 자료 직접 해석형으로, <보기> 없이도 충분히 성립하는 구조에 사용
- `choice_encoding_type`은 `independent_options`

5. `exhaustive_subset`
- 보기 3개(ㄱ, ㄴ, ㄷ)의 참/거짓을 판정한 뒤 "적절한 것만을 <보기>에서 있는 대로 고른 것은?" 발문 사용
- view_count는 3
- choice_encoding_type은 `subset_exhaustive`
- judgment_map에 ga, na, da만 사용 (ra 생략)
- choice_encoding_plan에 참인 보기 부분집합으로 ①~⑤ 구성
- 선지 예시 (참: ㄴ,ㄷ): ① ㄱ  ② ㄷ  ③ ㄱ,ㄴ  ④ ㄴ,ㄷ  ⑤ ㄱ,ㄴ,ㄷ

6. `label_matching`
- 자료(표, 연표, 분류도)에 빈칸 라벨(가)~(다)가 있고, 보기(ㄱ~ㄹ) 중 적절한 것을 각 라벨에 매칭하는 문제
- 발문 예: "(가)~(다)로 가장 적절한 것을 <보기>에서 고른 것은?"
- `choice_encoding_type`은 `permutation_matching`
- `judgment_map` 대신 `label_answer_map` 사용: { "가": "ㄴ", "나": "ㄹ", "다": "ㄷ" }
- 선지 형식: "① (가)-ㄱ, (나)-ㄴ, (다)-ㄷ"

7. `pair_selection`
- 발문이 2개의 판단 축을 동시에 묻는 문제 (예: 윤리유형 × 기업가정신)
- 발문 예: "다음 기사에 나타난 직업 윤리와 기업가 정신으로 가장 적절한 것은?"
- `choice_encoding_type`은 `independent_options`
- 선지는 (축1 값, 축2 값) 쌍으로 구성: "① 환경 윤리, 진취성"
- Blueprint에 `pair_axes` 필드 추가:
  { "axis_1": "직업 윤리 유형", "axis_2": "기업가 정신 유형" }

# [과목별 우선 선택 힌트]
- 성직: 채용 공고, 면접 장면, NCS 화면, 취업 프로그램 안내, 기사/칼럼은 `single_selection` 또는 `direct_statement` 우선
- 성직: 가치관/윤리/제도 비교에서 여러 진술을 동시에 판정해야 하면 `combination_judgment`
- 공일: 시스템명(MES/SCM/CRM/JIT/POP), 공정/기법/분류 중 하나를 고르는 문제는 `single_selection` 우선
- 공일: 보고서/표/기사에서 내용을 종합해 단일 판단을 하는 문제는 `direct_statement` 우선
- 공일·성직 공통: `(가)` 빈칸, 단계 절차, 순서도는 `blank_workflow` 우선
- 성직·공일 공통: 판정해야 할 독립 진술이 정확히 3개이고 "있는 대로" 고르게 할 때 `exhaustive_subset` 사용
- 성직·공일 공통: 연대표/분류표에 (가)~(다) 빈칸이 있고 보기를 매칭할 때 `label_matching` 사용
- 성직: 기사/사례에서 2개 개념을 동시에 식별할 때 (예: 윤리+정신, 가치+유형) `pair_selection` 사용
- 이론 적용 문항(해비거스트, 하렌, 홀랜드, 슈메너, 호프만, 클라크 등): theory_constraint 필수
