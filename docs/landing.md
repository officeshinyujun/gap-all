# GAP 랜딩 페이지 구성 제안

## 문서 목적

이 문서는 현재 코드베이스의 실제 프론트엔드 구조를 기준으로,
`/frontend/app/(auth)/landing/page.tsx`에 해당하는 랜딩 페이지를 어떻게 재구성하면 좋은지 제안하는 문서다.

이 문서는 추상적인 마케팅 문구 모음이 아니라,
현재 서비스가 이미 제공하고 있는 기능과 사용자 흐름을 바탕으로
**무엇을 랜딩에서 보여줘야 가입과 첫 학습 시작으로 자연스럽게 이어지는지**를 정리하는 데 목적이 있다.

---

## 1. 현재 서비스 구조를 기준으로 본 제품 정체성

현재 GAP 프론트엔드는 단순한 문제은행이 아니라,
아래 흐름을 가진 **직업계 고등학생 대상 AI 학습 플랫폼**에 가깝다.

```text
랜딩 → 로그인 → 메인페이지
→ 과목/단원 선택
→ 개념 학습
→ 빈칸 문제(q1)
→ 양방향 개념 문제(q2)
→ 실전 문제(q3) 또는 시험
→ 오답/복습
→ 필요 시 AI 채팅으로 보완
```

특히 코드상에서 확인되는 핵심 제품 축은 아래와 같다.

1. **교과서 기반 개념 학습**
   - `/study/{subject}/{chapter}/concept`
   - 카드형 개념 요약 + 핵심 포인트 + 출제 함정 + 논리 흐름

2. **단계형 학습 루프**
   - `concept → q1 → q2 → q3`
   - 학습이 한 번에 끝나는 것이 아니라 점진적으로 깊어지는 구조

3. **AI 생성 문제/시험**
   - 빈칸 문제, 개념 매칭 문제, 실전 시험 생성
   - subject/unit 범위 기반 생성

4. **복습 회수 구조**
   - `/review`
   - 틀린 개념 추천, 관련 개념 설명 재제공, 복습 시험 연결

5. **AI 튜터 채팅**
   - `/chat`
   - 과목/단원 범위를 설정한 뒤 학습 중 궁금증 해결

6. **학습 지속 장치**
   - 메인페이지 streak
   - 진행 중인 학습 이어하기
   - 북마크 개념 리스트
   - 프로필 기반 진행률/알림

즉 랜딩 페이지는 이 서비스를
**“수능특강을 기반으로, 개념 이해 → 문제 풀이 → 복습 → 질문까지 이어지는 폐쇄형 학습 루프”**
로 소개해야 한다.

---

## 2. 현재 랜딩 페이지의 한계

현재 `/landing`은 아래 요소만 가진 매우 미니멀한 구조다.

- 로고
- 서비스명 (`2830`)
- 짧은 설명 (`수능특강 기반 AI 학습 플랫폼`)
- `시작하기` CTA

이 구조는 깔끔하긴 하지만, 아래 정보가 전혀 드러나지 않는다.

1. **누구를 위한 서비스인지**
   - 직업계 고등학생용인지
   - 공업 일반 / 성공적인 직업생활 과목 중심인지

2. **무엇이 가능한지**
   - 단순 요약 앱인지
   - 문제 생성 앱인지
   - AI 튜터인지
   - 복습 앱인지

3. **왜 써야 하는지**
   - 기존 문제집/요약노트 대비 무엇이 다른지

4. **처음 들어온 사용자가 무엇을 기대해야 하는지**
   - 가입 후 바로 무엇을 하게 되는지

즉 현재 랜딩은
**CTA는 있으나 제품 이해가 부족한 상태**에 가깝다.

---

## 3. 랜딩 페이지의 역할 재정의

이 서비스의 랜딩 페이지는 단순 소개 페이지보다,
아래 4가지 역할을 맡는 것이 적절하다.

1. **서비스 대상과 과목 범위를 명확히 설명한다**
2. **학습 루프가 어떻게 작동하는지 한눈에 이해시킨다**
3. **AI 기능이 실제 공부 흐름 안에서 어떻게 쓰이는지 보여준다**
4. **가입 후 첫 학습 시작까지의 심리적 장벽을 낮춘다**

즉 랜딩은 “멋있어 보이는 화면”보다,
**처음 온 학생이 ‘아, 이건 내가 지금 공부를 시작할 수 있게 도와주는 서비스구나’라고 바로 이해하게 만드는 화면**이어야 한다.

## 4. 제안하는 최종 랜딩 구조

추천 구조는 아래와 같다.

```text
[1] Hero 섹션
[2] 대상/과목 설명 섹션
[3] 학습 루프 설명 섹션
[4] 핵심 기능 카드 섹션
[5] 실제 사용 화면 미리보기 섹션
[6] 차별점 섹션
[7] 추천 사용자 시나리오 섹션
[8] CTA 섹션
[9] 보조 FAQ 또는 안내 섹션
```

## 5. 섹션별 상세 제안

### 5.1 Hero 섹션

#### 목적

첫 화면에서 아래 세 가지를 동시에 전달해야 한다.

- 누구를 위한 서비스인가
- 무엇을 해주는가
- 지금 무엇을 누르면 되는가

#### 추천 카피 방향

메인 헤드라인 예시:

> 직업계 고등학교 학습을,
> 개념부터 문제 풀이까지 한 흐름으로.

또는

> 수능특강 기반 AI 학습 루프로,
> 공일·성직 공부를 끝까지 이어가게.

서브카피 예시:

> 교과서 요약, 빈칸 문제, 개념 매칭, 실전 시험, 오답 복습, AI 튜터까지.
> 공업 일반과 성공적인 직업생활을 끊기지 않는 학습 흐름으로 연결합니다.

#### CTA 구성

- Primary CTA: `시작하기`
- Secondary CTA: `학습 방식 보기`

#### 우측 비주얼 제안

정적인 일러스트보다 실제 제품 흐름을 압축한 mock이 좋다.

예:

- streak 카드
- 진행 중인 단원 카드
- 개념 카드 1장
- 퀴즈 결과 카드 1장
- AI 채팅 입력 UI

즉 “예쁜 추상 그래픽”보다
**실제 앱에 존재하는 조각들을 압축한 제품 콜라주**가 더 적합하다.

---

### 5.2 대상/과목 설명 섹션

#### 목적

서비스의 타깃을 명확히 보여준다.

현재 코드 기준으로 과목은 사실상 아래 두 축이 핵심이다.

- 성공적인 직업생활
- 공업 일반

#### 추천 구성

2-column 카드 또는 배지형 소개.

예:

- **성공적인 직업생활**
  - 직업 가치, 직업 생활, 진로·노동 개념 학습
- **공업 일반**
  - 산업 구조, 공업, 경영·생산·품질·안전 관련 학습

이 섹션은 사용자가
“이 서비스가 내 과목에 맞는지”를 즉시 판단하게 해준다.

---

### 5.3 학습 루프 설명 섹션

#### 목적

이 서비스의 가장 큰 장점은 기능 하나가 아니라,
**기능들이 순서 있게 연결된다는 점**이다.

현재 구현된 흐름을 랜딩에서 가장 강하게 보여줘야 한다.

#### 추천 구성

가로형 step flow 또는 모바일에서는 세로형 카드 스택:

1. **개념 읽기**
   - 교과서 기반 요약 카드로 빠르게 이해
2. **빈칸 문제 풀기**
   - 핵심 용어와 문장 구조 익히기
3. **개념 매칭 문제**
   - 정의와 개념을 스스로 회상
4. **실전 문제 풀기**
   - 실제 시험처럼 적용 연습
5. **오답 복습하기**
   - 틀린 개념만 다시 보완
6. **AI에게 질문하기**
   - 막히는 부분은 단원 범위 안에서 바로 해결

#### 핵심 메시지

> 한 번 보고 끝나는 학습이 아니라,
> 이해 → 확인 → 적용 → 복습까지 이어지는 구조

이 섹션은 랜딩 전체에서 가장 중요하다.

---

### 5.4 핵심 기능 카드 섹션

#### 목적

현재 제품 기능을 사용자의 언어로 번역해 보여준다.

#### 추천 카드 5개

1. **교과서 기반 개념 카드**
   - 핵심 요약, 표, 함정 포인트, 논리 흐름 제공

2. **AI 생성 퀴즈**
   - 단원별 빈칸 문제와 개념 문제 자동 생성

3. **실전 시험 생성**
   - 범위별 시험 생성, 문제 풀이, 결과 확인

4. **오답 중심 복습**
   - 틀린 개념 추천, 재학습, 복습용 문제 연결

5. **단원 범위 AI 튜터**
   - 과목/단원 범위를 설정하고 질문 가능

#### 중요 포인트

이 섹션은 “기능 목록”처럼 보이면 안 되고,
각 기능이 학습에서 어떤 역할을 하는지 보여줘야 한다.

예를 들어,
`AI 채팅`이 아니라 `공부하다 막히면 바로 물어볼 수 있는 AI 튜터`처럼 설명해야 한다.

---

### 5.5 실제 사용 화면 미리보기 섹션

#### 목적

Hero보다 더 구체적으로 제품 신뢰를 만든다.

현재 앱에는 이미 시각적으로 보여줄 수 있는 흥미로운 화면이 많다.

- 메인페이지의 streak + 진행 중 스터디
- 단원 페이지의 진행률 + 태그
- 개념 카드 학습 화면
- 빈칸 문제 화면
- 문제 렌더러 기반 실전 문제 화면
- 리뷰 화면
- AI 채팅 화면

#### 추천 구성

탭형 또는 carousel 형태:

- `개념 학습`
- `문제 풀이`
- `복습`
- `AI 튜터`

각 탭마다 실제 UI 스크린샷 또는 high-fidelity mock을 배치한다.

이 섹션은 구현 난이도는 있지만,
현재 코드베이스의 강점을 가장 잘 전달할 수 있다.

---

### 5.6 차별점 섹션

#### 목적

학생 입장에서 “왜 이 서비스를 써야 하는가”를 정리한다.

#### 현재 제품 기준 차별점

1. **교과서와 문제 풀이가 분리되지 않음**
   - 개념을 읽고 바로 관련 퀴즈/시험으로 이어짐

2. **오답이 다시 복습 루프로 연결됨**
   - 틀린 문제에서 끝나지 않고 다시 개념으로 회수됨

3. **AI가 학습 흐름 안에 들어와 있음**
   - 문제 생성용 AI, 개념 설명용 AI, 채팅 튜터가 분리된 역할로 작동

4. **공부를 이어가기 쉬움**
   - streak, 진행률, 이어하기 구조가 이미 존재함

#### 추천 표현 방식

비교표보다는 짧은 4개 포인트 카드가 적합하다.

---

### 5.7 추천 사용자 시나리오 섹션

#### 목적

랜딩에서 사용자가 자기 자신을 투영할 수 있게 한다.

#### 추천 시나리오

1. **처음 시작하는 학생**
   - “무엇부터 해야 할지 모르겠다면, 단원별 개념 학습부터 시작하세요.”

2. **시험 대비 중인 학생**
   - “단원 범위를 정하고 실전 문제를 생성해 점검할 수 있어요.”

3. **틀린 개념을 다시 잡고 싶은 학생**
   - “오답 기반 복습으로 약한 개념만 빠르게 보완하세요.”

이 섹션은 가입 전 사용자가
“내가 어떤 방식으로 쓰게 될지”를 상상하게 해준다.

---

### 5.8 CTA 섹션

#### 목적

랜딩 하단에서 다시 한 번 행동을 유도한다.

#### 추천 카피

> 공일과 성직 공부를,
> 개념부터 복습까지 한 흐름으로 시작해보세요.

버튼:

- `지금 시작하기`
- 보조 링크: `로그인하기`

신규/재방문 사용자를 모두 수용하려면,
하단 CTA는 단일 버튼보다 2개 옵션이 더 낫다.

---

### 5.9 FAQ 또는 보조 안내 섹션

#### 목적

가입 직전의 작은 불안을 줄인다.

#### 추천 질문

- 어떤 과목을 지원하나요?
- 공부는 어떤 순서로 진행되나요?
- AI 채팅은 아무 질문이나 가능한가요?
- 실전 문제는 어떻게 생성되나요?
- 복습은 어떻게 추천되나요?

이 섹션은 길게 갈 필요는 없고,
3~5개 정도로 간단히 두는 편이 좋다.

---

## 6. 정보 우선순위 제안

랜딩에서 가장 먼저 보여야 할 정보는 아래 순서가 적절하다.

1. **이 서비스가 누구를 위한 것인가**
2. **공부가 어떤 흐름으로 진행되는가**
3. **AI가 어디에 개입하는가**
4. **어떤 결과를 기대할 수 있는가**
5. **지금 무엇을 눌러야 하는가**

반대로 아래 정보는 랜딩에서 너무 앞에 오면 안 된다.

- 기술 스택 설명
- 관리자 기능 설명
- 내부 운영 도구 설명
- 지나치게 세부적인 시험 생성 설정

이건 전부 제품 운영에는 중요하지만,
학생용 랜딩에서는 핵심 메시지를 흐릴 수 있다.

---

## 7. 현재 코드 구조를 기준으로 한 메시지 포인트

현재 제품 구조를 가장 잘 반영하는 랜딩 메시지는 아래다.

### 핵심 한 줄

> 수능특강 기반 AI 학습 루프로, 공일·성직 공부를 끊기지 않게.

### 보조 메시지

- 개념 읽기에서 끝나지 않고 문제 풀이와 복습까지 이어집니다.
- 단원별 학습과 시험 생성, 오답 회수, AI 질문을 한 플랫폼 안에서 해결합니다.
- 지금 해야 할 다음 공부를 보여주고, 바로 이어서 학습하게 돕습니다.

## 8. 추천 화면 톤앤매너

현재 앱 구조상 랜딩은 너무 기업형 SaaS처럼 가기보다,
**학습 제품 + 가벼운 AI 학습 도우미**의 분위기가 더 적합하다.

추천 방향:

- 지나치게 무거운 B2B 문구 지양
- 학생이 이해 가능한 쉬운 표현 사용
- "공부 흐름"과 "이어하기"를 강조
- 기능 나열보다 “언제 어떻게 쓰는지”를 보여주기
- 시각적으로는 현재 앱의 카드형 UI와 연결되는 톤 유지

## 11. 최종 제안 요약

현재 GAP의 랜딩 페이지는 너무 간단해서,
실제 제품이 가진 강점인

- 단계형 학습 구조
- AI 기반 문제 생성
- 오답 복습 루프
- 단원 범위 AI 튜터

를 거의 전달하지 못하고 있다.

따라서 랜딩은 단순 브랜딩 화면이 아니라,
**“직업계 고등학생을 위한 AI 학습 루프”를 설명하는 제품 입구**로 바뀌어야 한다.

가장 중요한 것은 다음 한 문장이다.

> 이 서비스는 개념을 보여주는 데서 끝나지 않고,
> 문제 풀이·복습·질문까지 한 흐름으로 이어주는 학습 플랫폼이다.

랜딩이 이 메시지를 제대로 전달하면,
지금 코드베이스에 이미 존재하는 제품 가치가 훨씬 선명하게 보일 것이다.
