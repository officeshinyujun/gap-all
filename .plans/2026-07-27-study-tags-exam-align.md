## 해결 전략

**frequency 데이터를 ground truth로 사용한다.**

이미 검증된 실전 시험 빈출 개념 데이터가 `textbook/{sungjik,kongil}_frequency/N단원.json` 에 존재함. 각 단원당 6개씩, 총 120~121개 개념이 실제 기출 문제에서 추출되어 있음.

이 데이터를 그대로 개념 태그로 활용하면 **100% 시험 커버리지**를 즉시 달성할 수 있다. 추가로 1~3개는 교과서 맥락 태그로 보강한다.

### frequency 개념 → 태그 변환 규칙

| 규칙 | 예시 |
|------|------|
| 1차로 frequency 개념명 전체 사용 | `"하렌(Harren)의 진로 의사 결정 유형"` → 그대로 |
| 25자 초과 시 축약 (괄호 내용 보존) | `"경영 관리 순환 과정(계획-조직-지휘-통제)"` → OK |
| frequency 6개면 7~8개로 보강 | 기존 태그 중 frequency 개념과 중복 안 되는 것 1~2개 추가 |
| frequency 6개로 충분하면 그대로 | 추가 태그 없이 6개만 사용 |

## Implementation

### Phase 1: frequency 기반 태그 생성 (1분, LLM 불필요)

Python 스크립트 하나로 모든 concept 파일을 frequency 데이터로 교체.

```
입력: textbook/{sungjik,kongil}_frequency/N단원.json → concepts[].name
출력: textbook/concepts/{sungjik,kongil}/Unit_NN.json → {unitName, concepts: [...]}
```

- [ ] 1.1 `generate_exam_aligned_tags.py` 작성
  - frequency json 읽기 → concept name 추출
  - 25자 넘는 이름은 축약 (예: 앞부분 + 괄호만)
  - 6개 미만이면 기존 태그에서 보강
  - concepts 폴더에 저장
- [ ] 1.2 스크립트 실행 → 40개 파일 생성

### Phase 2: LLM 품질 보강 (15분, 선택적)

frequency 개념명이 지나치게 길거나 딱딱한 경우, LLM으로 가독성 개선.

- [ ] 2.1 LLM에 frequency 개념명 + 기존 태그를 입력으로 주고 "학생이 읽기 좋은 짧은 태그" 생성
  - 모델: gpt-4o-mini (비용 ~$0.01)
  - 각 단원별 1회 호출, 총 40회
- [ ] 2.2 생성된 태그가 frequency 개념을 모두 커버하는지 검증

### Phase 3: 검증 (3분)

- [ ] 3.1 시험 커버리지 100%: 모든 frequency 개념이 태그에 있는지 교차 검증
- [ ] 3.2 태그 수: 각 단원 6~10개 사이
- [ ] 3.3 UI 적합성: 25자 초과 태그 비율 20% 미만
- [ ] 3.4 중복 없음: 같은 단원 내 태그 중복 0건
